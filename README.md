# Shohan Ahmed Swazon - Portfolio

Personal portfolio website showcasing my engineering journey, projects, and skills.

## About

This is the portfolio website for **Shohan Ahmed Swazon**, a Mechanical Engineering student at Rajshahi University of Engineering & Technology (RUET).

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components
- Framer Motion animations
- jsPDF for CV generation

## Getting Started

The only requirement is having Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd shohan-s-engineering-studio

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

### Build for Production

```sh
npm run build
npm run preview
```

## Features

- Responsive design with mobile navigation
- Animated sections with Framer Motion
- CV download as PDF with embedded photo
- Contact form with copy-to-clipboard functionality
- Dark theme with cyan and orange accent colors
- Blueprint grid background pattern

## Sections

- **Hero** - Introduction with profile photo
- **About** - Personal highlights and strengths
- **Education** - Academic background
- **Skills** - Technical proficiencies with visual indicators
- **Projects** - Engineering projects showcase
- **CV Download** - Generate and download PDF resume
- **Contact** - Social links and contact information
